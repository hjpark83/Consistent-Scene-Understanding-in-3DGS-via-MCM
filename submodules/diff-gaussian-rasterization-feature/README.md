# Feature Gaussian Rasterization

Used as the feature rasterization engine for the paper "CF3: Compact and Fast 3D Feature Fields".
Codebase is originated from "3D Gaussian Splatting for Real-Time Rendering of Radiance Fields". 
If you can make use of it in your own research, please be so kind to cite the following.
